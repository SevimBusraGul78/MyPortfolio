# 💻 Personal Portfolio Website

ASP.NET Core MVC ile geliştirdiğim kişisel portfolyo web sitesi. Yazılım alanındaki çalışmalarımı, teknik yetkinliklerimi, deneyimlerimi ve projelerimi sergilemek amacıyla tasarladım.

Proje, SQL Server veritabanı ile entegre çalışan dinamik bir yapıya sahiptir. Yönetim paneli üzerinden site içerikleri kolayca yönetilebilmektedir.

## ✨ Özellikler

**Kullanıcı Arayüzü**
- Kişisel tanıtım ve hakkımda bölümü
- Teknik yetkinliklerin listelenmesi
- İş ve proje deneyimlerinin gösterilmesi
- Portfolyo ve referans alanları
- İletişim formu
- Responsive tasarım

**Admin Paneli**
- Dashboard ve istatistik ekranı
- Hakkımda içeriklerini yönetme
- Deneyim ekleme, listeleme, güncelleme ve silme
- Portfolyo ve yetenek yönetimi
- Referans ve sosyal medya yönetimi
- Gelen mesajları listeleme ve görüntüleme
- Mesajları okundu / okunmadı olarak işaretleme

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|---|---|
| C# | Backend geliştirme |
| ASP.NET Core MVC | Web uygulaması mimarisi |
| Entity Framework Core | ORM ve veritabanı işlemleri |
| SQL Server | Veritabanı |
| LINQ | Veri sorgulama |
| HTML5 & CSS3 | Arayüz geliştirme |
| JavaScript | Dinamik etkileşimler |
| Bootstrap | Responsive tasarım |

## 🏗️ Mimari

Proje, MVC (Model-View-Controller) mimarisi kullanılarak geliştirilmiştir.

- **Model:** Veri modellerini temsil eder.
- **View:** Kullanıcı arayüzünü oluşturur.
- **Controller:** Uygulama akışını ve istekleri yönetir.
- **ViewComponent:** Tekrar kullanılabilir dinamik bileşenler oluşturur.
- **Entity Framework Core:** Veritabanı işlemlerini gerçekleştirir.
